# Meme Coin AI Analyst

AI-dashboard voor Solana en Ethereum.

- Nieuwe en bestaande meme coins scannen
- Kansen en risico's analyseren
- Scaninterval: 2 minuten
- Maximale poolleeftijd: 7 dagen
- Geen wallet of automatische transacties

Dit dashboard geeft analyses en signalen, geen financieel advies.
